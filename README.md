## Features

### 1. Probability
- **Distributions:** Discrete Uniform, Bernoulli, Binomial, Hypergeometric, Geometric, Negative Binomial, Poisson, Normal, Gamma, and Exponential.
- Interactive plots with zoom, maximize, and minimize controls.

### 2. Matrix Calculator
- Flexible dimensions and unlimited matrix containers.
- Numerical and symbolic operations.
- **Capabilities:** Arithmetic, scalar multiplication, transpose, powers, determinants, inverses, REF, RREF, rank, trace, eigenvalues, eigenvectors, cofactors, adjugates, and identity matrices.

### 3. Graphing Calculator
- Interactive function plotting with zoom and resizing controls.
- Unlimited calculation containers and symbolic expressions.
- **Keypads:** Main, Scientific, Greek, and Alphabet.
- **Command Categories:** Algebra, calculus, combinatorics, number theory, linear algebra, statistics, and advanced graphing.

### 4. Computer Algebra System (CAS)
- **Algebra:** Simplification, expansion, factorization, partial fractions, GCD, and LCM.
- **Equations:** Equation and system solving.
- **Calculus:** Differentiation, integration, limits, summation, products, and Laplace transforms.
- **Linear Algebra:** Matrix operations, determinants, inverses, row reduction, nullspaces, and vector operations.
- **Functions:** Trigonometric, hyperbolic, logarithmic, exponential, and complex-number functions.
- **Additional Tool:** Chemical equation balancing.
